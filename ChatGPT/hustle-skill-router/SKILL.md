# Hustle Skill Router

Hustle is a Nigeria-first, mobile-first capability-to-opportunity ecosystem. Its core loop is Skill → Demonstration → Discovery → Trust → Opportunity → Transaction → Reputation → Growth.

When helping with Hustle, first retrieve or rely on verified current project context from the connected GitHub repository `realxpen/hustle-economy-of-you`, especially `AGENTS.md`, `PROJECT_STATE.md`, relevant Knowledge files, and Decisions. If GitHub is unavailable, disclose that limitation and use available supplied context rather than inventing repository state.

The repository includes reviewed third-party skill guidance under `.agents/skills/` and a registry at `Knowledge/Technical/SKILLS_REGISTRY.md`. Choose only the guidance relevant to the task:

- React Native/Expo work: react-native-architecture
- Web/admin work: nextjs-app-router-patterns, responsive-design, tailwind-design-system
- UI/UX: frontend-design, design-system-patterns, accessibility-compliance
- APIs: api-design-principles, openapi-spec-generation
- Auth and capability permissions: auth-implementation-patterns
- JavaScript and state: modern-javascript-patterns, react-state-management

Do not claim the above skills are directly installed in this ChatGPT workspace merely because they exist in GitHub. Read the upstream skill files through a connected repository tool if needed and permitted; otherwise use the local guidance above.

**Authority and execution:** Current founder decisions and Hustle's documented AED/AGENTS policies outrank external examples. Never introduce role switching, new auth providers, unapproved frameworks, or architecture changes based on a generic skill. Never execute third-party skill commands or access production systems or credentials without the appropriate approval. Reuse existing code, preserve review gates, and report tests actually performed.

For other Skill Issue skills listed as DEFERRED/RESTRICTED/NOT APPLICABLE, do not install or execute them automatically. Recommend source and risk review if a specific need arises.

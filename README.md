# Hustle — The Economy of You

Hustle is a mobile-first, content-first capability-to-opportunity ecosystem for discovering, trusting, hiring, buying from, learning from, and growing skilled people.

## Current build status

- AED cycle: Build
- MVP phase: Phase 2 — Authentication + Unified Account System
- Deployment target: Vercel previews (web first)
- Product rule: one account, progressive capabilities, no role switcher
- Development auth provider: Supabase behind an adapter boundary

## Phase 2 preview routes

- `/` — phase preview
- `/auth` — sign in, sign up, phone OTP and password recovery entry
- `/onboarding` — unified identity setup
- `/account` — capability-aware account preview
